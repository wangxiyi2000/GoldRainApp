# 《搬砖爆金币》产品定义文档（PRD）

> 版本：v1.3 ｜ 日期：2026-10-11 ｜ 状态：M1 已完成，开发中
>
> **v1.3 变更（免打卡模型）**：删除"手动打卡"这一动作。上班/下班时间由设置决定，金币永远按「今天的上班时间 → 现在」推算——**什么时候打开 App 都能看到金币在按上班时间涨**。同时：过了下班时间自动收工入库；从首次使用日到昨天，每个工作日自动补一条全勤战报。迟到早退不做判断。
>
> **v1.3.1 补强（周末不算钱）**：把"只算工作日"的口径从"补历史"扩展到**当天**——周六/周日打开 App 显示"今天休息"，金币恒为 0，**过点也不会自动入库**（原实现漏了这一步，周末会白记一天工资）。唯一例外是跨天夜班：周五晚开的班延续到周六凌晨仍算搬砖。

---

## 1. 一句话定义

**一款"上班即爆金币"的情绪价值 App：到了上班时间，金币自动随着你的每一分钟工作华丽地爆满屏幕，下班结算"今日工资战报"，让打工人亲眼看着自己的血汗钱可视化落地。**

> **v1.3 核心设计原则：零打卡焦虑。** 用户不需要打卡、不需要记得打开 App。上班时间一到，金币就按你设置的时间自动开始爆；下班时间一到，自动收工入库。App 只是"看板"，不是"任务"。

- 产品定位：纯情绪价值 / 解压 / 玩梗工具，**不涉及真实金钱、不联网社交、不采集隐私**
- 目标用户：一线打工人（自用 + 朋友间传播玩梗）
- 平台：Android 优先（自己侧载安装），后续可选 iOS
- 商业模式：**无**（个人作品，先做爽再说）

---

## 2. 为什么值得做（产品洞察）

| 打工人痛点 | 本产品的回应 |
|---|---|
| 工资是月底才到账的抽象数字 | 把时薪拆成**每秒实时爆金币**，看得见摸得着 |
| 上班如上坟，时间感麻木 | 屏幕上金币哗哗爆出，"我在赚钱"的即时反馈 |
| 摸鱼有负罪感 | 金币照给（工资本来就该拿），但回到前台会弹一句"你摸鱼了 23 分钟"，调侃一下 |
| 下班时刻毫无仪式感 | 「今日战报」结算动画：今日爆金币 ×N 枚、相当于X杯奶茶/X顿火锅 |

**核心情绪曲线**：到点自动开爆（惊喜）→ 干活中金币狂爆（爽）→ 摸鱼回来被调侃"你摸鱼了 23 分钟"（好笑）→ 到点自动收工结算（成就感爆棚）。

## 3. 核心玩法循环

```
上班时间到 ──► 金币自动实时爆屏（按你的时薪换算，无需任何操作）
   │                      │
   │                      ├─ 摸鱼提示：回到前台弹"你摸鱼了 23 分钟"（金币照给，不惩罚）
   │                      └─ 突发彩蛋：整点金币雨、连续专注奖励
   ▼
下班时间到 ──► 自动收工，今日战报（金币总数、搬砖时长、换算奶茶数）自动入库
   │
   └─► 金币累积进"金库"，解锁华丽皮肤/彩蛋动画
```

### 3.1 功能优先级

**P0（MVP 必须有，第一版就能爽）：**
1. **免打卡**：上班/下班时间由设置决定，到点自动开始/自动收工，用户不需要点任何按钮（v1.3 起取代"手动打卡"）
2. 时薪设置（用户自己填 **月薪、上班时间、下班时间**，自动算出时薪，也允许手改）
3. 金币实时爆屏动画（核心！粒子特效 + 金币精灵 + 音效可选）
4. 下班结算「今日战报」：今日金币数、工作时长、换算成奶茶/火锅的购买力
5. 金库总资产页（累积所有金币）
6. 振动反馈（金币爆出时轻微震动，加强爽感）

**P1（第二版加）：**
7. 摸鱼提示：切到后台再回来，提示"你摸鱼了 23 分钟"（金币照给，只提示不惩罚）
8. 整点彩蛋：每到整点触发一次金币雨 + "恭喜存活到 X 点"
9. 皮肤系统：金币换皮肤（红包雨、钻石雨、奶茶雨、工资条雨）
10. 历史记录：每日战报日历，看自己"爆金币曲线"

**P2（有余力再说）：**
11. 成就系统（"连续爆金币 30 天""单日破万"）
12. 桌面小组件：不打开 App 也能看到今日金币数
13. 灵堂模式彩蛋：周五下班专属烟花
14. iOS 版本

### 3.2 明确不做（防跑偏）

- ❌ 不接真实银行/支付，金币是**纯虚拟玩梗货币**
- ❌ 不做社交/排行榜（避免合规和服务器成本，纯本地）
- ❌ 不做"提现"暗示性文案（哪怕玩梗也容易引投诉）
- ❌ 不采集任何个人数据，无账号系统，全部本地存储

## 4. 关键规则设计

### 4.1 金币换算公式

```
每日工时 = 下班时间 - 上班时间                   // 用户自己设置，例：18:00 - 09:00 = 9 小时
时薪 = 月薪 ÷ (每月工作日 × 每日工时)          // 例：10000 ÷ 22 ÷ 9 ≈ 50.5 元/时
每秒金币数 = 时薪 × 1（1元=1枚金币）÷ 3600       // ≈ 0.014 枚/秒（约 71 秒爆 1 枚）
```

- 可设置项（用户自定义）：**月薪、上班时间、下班时间**；每月工作日默认 22 天，也允许调整
- **账本口径（严格真实）**：金币数 = 实际赚到的钱，**1元=1枚，不做任何放大**；战报、金库里的数字就是真金白银
- **显示层视觉倍率（只管好看，不改账本）**：屏幕出币密度 = 账本速率 × 视觉倍率 N。默认 N=100（账本 ≈0.014 枚/秒 → 屏幕每秒爆 1~2 枚，保持爆屏爽感）。**倍率只影响画面，不影响战报/金库数字**；设置里可调，N=1 即"写实慢节奏"模式
- 屏幕显示策略：金币**爆出瞬间**是华丽的（放大、旋转、闪光、飘字 "+1"），爆出后落入底部"金堆"累积；每 60 秒触发一次小额"金币瀑布"（一次爆 30~50 枚，避免视觉疲劳）
- 视觉节奏：常态匀速爆 → 整点/专注奖励时爆量 ×10，制造高潮

### 4.2 计时规则（v1.3 免打卡模型）

**核心：没有"打卡"这个动作。** 上班/下班时间来自设置，金币永远按「今天的上班时间 → 现在」推算。

一天有四种状态，由当前时刻自动决定：

| 状态 | 判定 | 金币 | 界面 |
|---|---|---|---|
| **休息日** | 周六 / 周日 | **恒为 0，不刷新，不入库** | 静态首页："今天休息 🛌 / 周末不算钱，好好休息 · 周一 09:00 开爆" |
| **上班前** | 现在 < 上班时间 | 0，不刷新 | 静态首页："还没到点 ⏰ / 09:00 开爆 / 还有 1h23m" |
| **搬砖中** | 上班时间 ≤ 现在 < 下班时间 | 每秒实时涨 | 搬砖页：大数字 3 位小数连续跳动 |
| **已收工** | 现在 ≥ 下班时间 | 定格在**全天工资**，不刷新 | 静态首页 + 「查看今日战报」入口 |

- **周末不算钱（v1.3.1 补强）**：这个口径贯穿全流程——周六/周日打开 App 显示"今天休息"、金币恒为 0、**过点也不会自动入库**；历史补齐同样只补工作日。唯一例外是**跨天夜班**：周五 22:00 开的班延续到周六凌晨，仍算搬砖中（在班的班次不被打断）
- **按时间推算，不依赖前台计时器**：切后台、杀掉进程、重启、隔几天再打开，数字都按真实经过的时间算，不会丢
- **不管迟到早退**：不做上班前/下班后的偏差判断，到点就是到点
- **自动收工入库**：过了下班时间，当天战报**自动**写进金库（不需要点任何按钮）
- **自动补齐历史**：从「首次使用日」到昨天，**每个工作日（周一~周五）**自动补一条全勤战报；周末不补
- **参数持久化**：月薪、上班时间、下班时间、首次使用日全部本地存储，下次打开自动恢复
- **改设置会重算今天**：若今天已入库，改完设置后按新设置重新生成今天的战报（历史记录保持不动）
- **摸鱼提示（只提示不惩罚）**：回到前台时弹一条「你摸鱼了 23 分钟」，金币照给，纯调侃

> v1.3 删除的旧规则：手动上班/下班打卡、防重复打卡、忘打卡次日补结算（上限 12h）。这些在免打卡模型下自动失去意义。

### 4.3 今日战报（情绪价值核心场景）

过了下班时间后，全屏结算页：
- 大数字滚动：**今日爆金币 454.545 元**（月薪 10000 ÷ 22 天 = 454.545）
- 换算文案随机吐槽：`≈ 奶茶 30.3 杯` / `≈ 一顿海底捞的 1/3` / `≈ 离首付又近了 0.0001%`
- 金币瀑布 + 彩带庆祝动画
- "明天继续爆，打工人！" 收尾文案

## 5. 视觉与交互基调

- **主色**：土豪金（#FFD700 系）+ 深色背景（夜间模式友好，办公室偷偷看也显高级）
- **风格关键词**：华丽、爽、带点自嘲的幽默感
- 金币 = 精灵图（旋转 3~4 帧动画），不是丑丑的圆形色块——**这是爽感的生命线**
- **单枚金币要大、要华丽**：尺寸显眼 + 旋转/闪光/落地弹跳 + 强音效，强化“每一枚都值钱”的珍贵感
- 动效优先级高于一切 UI 精致度：宁可按钮朴素，金币必须华丽
- 文案口吻：打工人黑话（"血汗钱可视化工程""搬砖收益实时到账"）

## 6. 非功能需求

| 项 | 要求 |
|---|---|
| 电量 | 前台爆金币时功耗可控（粒子数上限、60fps→可选 30fps 省电模式） |
| 隐私 | 零权限起步：不需要网络、定位、通讯录。仅"振动"权限可选 |
| 数据 | 全部本地（SharedPreferences/SQLite）；**用户参数（月薪/上下班时间）与当前会话自动持久化**，重开 App 不用重新输入；卸载即清零，换机不做迁移 |
| 包体 | < 30MB，无第三方大型 SDK |
| 稳定性 | 计时准确性容忍 ±1 分钟/天，金币数仅作娱乐展示不作记账依据 |

## 7. 技术选型结论（详见开发手册）

- **框架：Flutter**（一套代码 → Android/iOS；UI 动效能力强，非常适合粒子金币）
- 渲染：自绘 `CustomPainter` + 金币精灵图 + 简单物理（重力、弹跳）
- 存储：`shared_preferences`（MVP）→ SQLite（历史记录后升级）
- 分发：Android 先打 APK 自己装（不需要上架）；iOS 再议（需要 ¥688/年 开发者账号）

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 新手开发进度失控 | 严格按手册里程碑推进，每阶段都能在手机上看到东西 |
| 动效做不出"华丽感" | 手册提供现成粒子系统代码；金币精灵图先用免费素材库 |
| 坚持不下去 | M1 结束就有可玩的数字版，尽早给自己正反馈 |
| 长期后台耗电被系统杀 | 设计上就接受"前台爆金币"，不做保活（合规且省心） |
